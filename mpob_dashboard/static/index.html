State Breakdown Matrix: CPO Production (Tonnes)

Implied Area = CPO Production / CPO Yield (tagged [CALC]), actual months only. It is not planted area: production is counted at the mill, so cross-state FFB flows distort it (Pulau Pinang ~6×, Melaka ~0.5×), and Peninsular yields cover a narrower base (~1.2–1.3×). Use Official MPOB Mature Ha for area; the Implied ÷ Official ratio (amber when >10% from 1.0) is a mill-catchment / data-consistency check. Sabah and Sarawak sit near 1.0.
